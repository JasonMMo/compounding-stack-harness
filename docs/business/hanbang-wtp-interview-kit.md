# 한방 RAG WTP 인터뷰 키트

> 작성: PM (Growth-18) | 날짜: 2026-06-30
> 용도: founder가 인쇄 후 대면/전화 인터뷰에서 직접 사용. 이론 최소화, 실전 밀도.
> **v2 재조준(2026-07-01)**: 건보 급여기준 검색 가설 → **자보(자동차보험) 한방 삭감 방어** 가설로 재조준. 근거: `knowledge/wiki/sources/deep-research-hanbang-billing-pivot-2026-07.md` (건보 페인 미확증, 확증 분쟁은 전부 자보 채널). 데모 시연(§3)의 5개 건보 쿼리는 **능력 시연용으로 그대로 유지** — 자보 데모가 아직 없으므로 "이런 식으로 근거 조항을 찾아 인용한다"는 것만 보여주고, 자보 삭감 페인은 §4 구두 프로빙으로 검증한다.

## 1. 목적·가설

**검증 가설**
자보(자동차보험) 한방 진료 비중이 높은 한의원 원장 및 청구담당자는, 보험사·심평원 위탁심사의 자보 삭감·감액·환수에 대응하기 위해, 사내망 self-host RAG(자보 진료수가 기준·심사 근거 하이브리드 검색 + 자체 삭감 이력 축적)에 월 X만 원 이상을 지불할 의향이 있다.

**Kill-criteria (유료화 보류 기준) — 가격이 아닌 *페인 신호* 로 판정**
> 우리는 아직 가격 근거가 0이다 → **절대 가격 임계값을 미리 박지 않는다**(앵커링·자기충족 위험). van Westendorp 4값은 *수집·기술* 만 하고, 보류 게이트로 쓰지 않는다(가격 밴드는 결과물).

5명 중 3명 이상이 ①자보 청구 비중이 낮거나(월 전체 청구의 소수, 대략 10% 미만 목안) **또는** ②자보 삭감·감액 경험이 경미(월 1건 이하)이거나 **또는** ③"한의맥·기존 방식(보험사 대응 인력·세무사)으로 충분하다"고 응답하면 → 유료화 보류, 무료 리드 마그넷 전환 검토.
> founder는 인터뷰 *전* 목표 ARPU/손익분기 가격을 내부 기준선으로 적어두되(아래 §6 수집한 WTP 밴드와 사후 대조용), 인터뷰 중 발설 금지.
> 자보 삭감 페인의 절대 '사이즈'(건수·금액)는 우리 쪽에 데이터가 0 — 단정하지 말고 §4(b) 프로빙으로 원장 답변에서 그대로 추출한다.

## 2. 대상·표본

**대상 페르소나**

| 페르소나 | 역할 | 핵심 관심사 |
|---|---|---|
| A. 개원 원장 | 최종 구매결정권자 | 자보 삭감·환수 리스크, 보험사 분쟁, 비용 승인 |
| B. 자보 청구담당 직원 | 일상 사용자·내부 추천자 | 심사 근거 검색 속도, 이의신청 문서 신뢰도, 번거로움 |

**최소 표본**: 페르소나 A 3명 + 페르소나 B 2명 = **최소 5명** (양적 결론 불가, 방향 판단용).

**모집 경로 제안 — 자보 진료 비중이 높은 한의원 우선**
- 스크리닝 질문(모집 단계에서 먼저 확인): "교통사고 환자(자보) 진료 보시나요? 월 청구 중 자보 비중이 어느 정도 되세요?" — 자보 비중이 사실상 0인 원장은 표본에서 제외.
- 원장: 한의사협회 지역 분회 SNS 채널(카카오 오픈채팅), 지인 소개 1-hop, 교통사고 특화 한방병원·한의원(간판·홍보에 "교통사고 후유증" 명시하는 곳) 우선 접촉
- 청구담당: 원장 인터뷰 후 "자보 청구 담당자분 5분만 부탁드려도 될까요?" 연결
- 조건: 2026년 현재 자보(자동차보험) 진료 청구 활성 한의원. 한의원장 단독 개원 또는 2~5인 소규모 우선.
- 방법: 30~40분 대면 또는 화상. 데모 시연 포함(단, 데모는 건보 능력 시연 — §3 참고).

## 3. 데모 시연 스크립트

> **v2 안내**: 아래 5개 시나리오는 모두 건보(NHIS) 급여기준 고시 검색이다. 자보 진료수가 기준 corpus는 아직 인제스트 전이므로 자보 전용 데모는 없다. 이 섹션의 목적은 "근거 조항을 찾아 정확히 인용하는 능력"을 보여주는 것뿐 — 시연 직후 "지금 보신 건 건보 기준 검색이고, 저희가 여쭙고 싶은 건 이 방식을 **자보 진료수가 기준·심사 근거**에 적용했을 때 원장님께 도움이 될지입니다"라고 구두로 연결하고 §4로 넘어간다.

## 4. WTP 프로빙 시퀀스

> 주의: 가격 숫자를 먼저 말하지 않는다. 원장이 먼저 말하게 한다.

### (a) 현행 대안 정량화 — 건보 기준 확인 경로 (참고용, 페인 크기 비교 기준선)

1. "지금 급여기준 고시 확인은 주로 어디서 하세요? (HIRA 포털 / 복지부 사이트 / 동료·세무사 문의 / 기타)"
2. "한 번 확인에 평균 몇 분 걸리세요? 한 달에 몇 번 정도 필요하세요?"

### (b) 자보 삭감 사이즈 추출 — 핵심 프로빙 (우리는 데이터 0, 여기서 그대로 추출)

> 이 섹션이 이번 인터뷰의 핵심이다. 원장이 말한 숫자를 그대로 §6 템플릿에 옮겨 적는다 — 우리가 추정·단정하지 않는다.

3. "월 전체 진료 청구 중에 자동차보험(자보) 청구가 차지하는 비중이 어느 정도 되세요? 건수로도, 금액으로도 대략 말씀해 주시겠어요?"
4. "최근 1년 안에 자보 진료비가 삭감되거나 감액된 적 있으세요? 한 달 평균 몇 건, 금액은 얼마나 되나요?"
5. "삭감이 주로 어떤 항목에서 나오나요? (입원일수 / 시술 횟수·종류 / 상병명 인정 여부 / 기타)"
6. "보험사나 심평원 위탁심사 결과에 이의신청 해보신 적 있으세요? 한 달 평균 몇 건, 건당 준비 시간은 얼마나 걸리세요?"
7. "자보 진료수가 기준(국토부 고시)이 건보 기준이랑 헷갈리거나, 어느 게 맞는 기준인지 확인이 어려웠던 경험 있으세요?"

### (c) Self-host + 사적 데이터 축적 프로빙

8. "원내 환자 데이터나 청구 데이터가 외부 클라우드 서버에 올라가는 것, 어떻게 생각하세요?"
9. "EMR 납품사나 복지부 지침에서 '보안성 확보' 관련 말씀 들어보신 적 있으세요?"
10. "만약 이 검색 도구가 외부 서버가 아니라 원내 컴퓨터에서만 돌아간다면 도입 결정에 영향이 있을까요? 어느 정도나?"
11. "우리 병원이 그동안 겪었던 자보 청구·삭감·이의신청 이력을 데이터로 쌓아서, 다음 삭감 대응 근거로 활용할 수 있다면 어떠세요? 그런 게 있으면 쓰시겠어요?" *(대안 A — 사적 데이터 인텔리전스 — 자보에서 살아나는지 검증)*

### (d) van Westendorp 4질문

> "데모 보신 기준으로, 이 방식을 자보 삭감 방어에 적용한다고 가정하고 월 구독 가격을 생각해 보시면..."

12. (너무 비싸다) "얼마부터면 '이건 너무 비싸다, 고려 안 하겠다'고 생각하실 것 같아요?"
13. (비싸지만 고려 가능) "얼마면 '비싸긴 한데 가치는 있다'고 느끼실 것 같아요?"
14. (적당히 싸다) "얼마면 '가격이 괜찮네, 부담 없다'고 느끼실 것 같아요?"
15. (너무 싸서 의심) "얼마면 '이 가격이면 뭔가 부족한 것 같다, 믿기 어렵다'고 느끼실 것 같아요?"

> 응답 후: "혹시 연간 납부 vs 월납 중 어떤 방식이 편하세요?"

### (e) 구매 의사결정권자·예산주기

16. "현재 EMR(차트 프로그램) 어디 쓰세요? 자보 청구는 한의맥으로 하세요, 아니면 다른 방식이세요?" *(EMR/한의맥 번들 vs 독립 — GTM OQ 충족용)*
17. "한의맥에서 삭감 방어나 심사 예측 관련 기능 써보신 적 있으세요? 있다면 어떤 기능이고, 부족한 점은 뭐였어요?"
18. "이런 도구 도입 결정은 원장님 혼자 하시나요, 아니면 원무장님이나 세무사와 상의하세요?"
19. "보통 이런 소프트웨어 비용은 어느 예산 항목에서 나오나요? (의료소모품 / 사무용품 / 교육연수비 / 기타)"
20. "언제쯤 도입 결정이 가능할 것 같으세요? (즉시 / 다음 삭감·환수 발생 시 / 미정)"

## 5. 반론 대응표

| 예상 반론 | 변별 포인트 | 후속 질문 |
|---|---|---|
| "한의맥으로 충분한데요" | 한의맥(협회 직영)은 자보 **청구** 접수·전송은 지원하나, 삭감 방어·심사 예측·이의신청 근거 검색 기능은 확인된 바 없음(기능 백지). 청구 vs 방어는 다른 문제. | "한의맥에서 삭감된 건에 대해 이의신청 근거 조항을 찾아주는 기능이 있나요? 써보신 적 있으세요?" |
| "보험사 상대로는 어차피 못 이겨요" | 확증 반례 존재(서정철 원장, 약침시술료 환수 소송 승소). 승소 사례=근거 문서 확보가 관건이었을 가능성. 원장의 실제 경험·인식을 직접 확인. | "삭감·환수 건에 이의신청하거나 소송까지 가신 적 있으세요? 그때 근거 자료는 어떻게 준비하셨어요? 결과는요?" |
| "그냥 무료 AI(챗GPT 등)로 찾아보면 되잖아요" | 자보 진료수가 기준(국토부 고시)은 건보 기준보다 자료가 더 마이너·비정형이라 범용 LLM 환각 위험이 더 큼. 원문 인용 없는 답변은 심사·이의신청에서 근거로 못 씀. | "챗GPT 같은 데 자보 진료수가 기준 물어보신 적 있으세요? 그 답변을 심사 이의신청 근거로 그대로 쓰실 수 있을 것 같으세요?" |
| "맥챗(KIOM) 있지 않나요? 무료인데" | 맥챗=국민 대상 일반 한의학 정보. 원내 자보/급여기준 고시 검색 기능 없음. 대상 사용자·목적 완전히 다른 도구. | "맥챗에서 자보 진료수가 기준 조항 찾아보신 적 있으세요?" |
| "직원이 알아서 찾으면 되는 거 아닌가요" | 직원 탐색 시간=인건비. 오탐색=삭감·환수 리스크. 숙련도 의존. | "담당 직원 바뀌면 자보 청구·이의신청 인수인계 어떻게 하세요? 그 시간 비용 생각해 보신 적 있으세요?" |
| "도입하려면 IT 설치가 귀찮을 것 같아요" | 설치=원내 PC 1대, 브라우저 접속. 별도 서버 불필요(소규모 원내 Docker). 런북 제공. | "지금 EMR도 원내 설치형이신가요? 그때 누가 설치해 드렸어요?" |
| "지금 당장 삭감 문제 없어서 필요 없을 것 같아요" | 한의협·한방병협 2023 공동성명("일괄삭감" 우려)이 시사하듯 업계 전반의 리스크. 지금 없어도 다음 심사 주기에 발생 가능. | "동료 원장님들 사이에서 자보 일괄삭감 얘기 들어보신 적 있으세요? 어떻게 대응하고 계세요?" |
| "한의사 협회에서 자료 다 주지 않나요" | 협회 자료=요약·해설·성명. 개별 삭감 건 이의신청에는 원장 병원 고유의 근거·이력이 필요. | "이의신청 할 때 협회 자료만으로 충분했나요, 아니면 직접 근거를 더 찾으셔야 했나요?" |

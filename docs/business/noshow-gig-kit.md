**전화 받다가 시술 흐름 끊기신 적, 몇 번이세요?**

가위 들고 있는데 전화 울리고, 예약 확인 카톡 하나하나 손으로 보내고, 그러다 놓친 손님은 그냥 안 오시고... 미용실·피부관리실·네일샵 사장님이라면 하루에도 몇 번씩 겪는 일입니다.

**이렇게 해결합니다**

- 손님이 전화 없이 직접 시술 선택하고 원하는 시간에 예약하는 **온라인 예약 링크**
- 예약 확정되면 바로, 그리고 하루 전·당일에 자동으로 나가는 **카톡/문자 리마인더**
- 리마인더에 반응 없는 손님은 **노쇼 위험**으로 화면에 표시 — 사장님은 보기만 하면 됩니다
- 손님이 취소하면 대기 중인 다른 손님에게 자동으로 빈 자리를 제안해서 **매출 공백을 채워드립니다**

**어떻게 작동하는지**

1. 손님이 카톡 링크나 인스타 프로필의 예약 버튼을 눌러 시술·시간을 고릅니다.
2. 예약이 잡히면 확인 메시지가 즉시 나갑니다. 하루 전, 당일에도 자동으로 리마인더가 나갑니다.
3. 답이 없으면 사장님 화면에 "노쇼 위험" 표시가 뜹니다. 취소가 나면 대기 손님에게 자동으로 제안 메시지가 갑니다.

**직접 눈으로 보고 결정하세요**

말로만 설명드리지 않습니다. 실제로 손님이 예약하고 사장님이 카톡을 받는 과정을 **라이브 데모**로 먼저 보여드립니다. (아래 "무료 체험" 참고)

**받으시는 것**

- 가게 이름·시술 메뉴·영업시간에 맞춘 온라인 예약 페이지
- 예약확정/전일/당일 리마인더 자동발송 설정 (카카오 알림톡 또는 문자)
- 사장님용 예약 관리 화면 (오늘 예약, 노쇼 위험, 대기명단)
- 설치·설정 A to Z 대행 (사장님은 손님 안내 링크만 공유하시면 됩니다)

### A-5. 구매자 FAQ

**Q1. 네이버 예약이랑 뭐가 다른가요?**
네이버 예약은 예약을 받는 도구입니다. 노쇼가드는 예약을 받은 **다음**이 다릅니다 — 리마인더를 자동으로 보내고, 답 없는 손님을 노쇼 위험으로 미리 알려주고, 취소된 자리를 대기 손님으로 자동으로 채웁니다. 네이버 예약과 같이 쓰셔도 되고, 저희 예약 링크로 대체하셔도 됩니다.

**Q2. 카톡은 진짜 발송되나요?**
네. 실서비스는 카카오 알림톡(사업자 등록 필요) 또는 문자(솔라피 등, 개인사업자도 가능)로 실제 발송되도록 설정해 드립니다. 크몽에서 보시는 데모는 발송 시뮬레이션(화면 안에서 카톡처럼 보여드리는 것)이며, 실제 설정은 셋업 과정에서 사장님 상황에 맞는 채널로 안내드립니다.

**Q3. 우리 가게에 맞게 되나요?**
네. 시술 메뉴, 영업시간, 리마인더 문구, 노쇼 기준 등을 가게 상황에 맞춰 설정해 드립니다. 상담 시 여쭤보고 반영합니다.

**Q4. 유지비는 왜 내나요?**
메시지가 매일 나가려면 발송 인프라가 계속 살아 있어야 하고, 오류가 나면 바로 확인해서 고쳐야 합니다. 월 관리비는 이 유지·모니터링·업데이트 비용입니다. 셋업만 하고 방치되는 서비스가 아닙니다.

**Q5. 해지하면 어떻게 되나요?**
다음 결제 주기부터 서비스가 중단됩니다. 그동안 쌓인 예약·손님 데이터는 요청 주시면 정리해서 보내드립니다.

**Q6. 컴퓨터를 잘 몰라도 쓸 수 있나요?**
네. 사장님은 손님께 예약 링크만 공유하시면 되고, 예약 현황은 화면 하나에서 보기만 하시면 됩니다. 설정은 저희가 대행합니다.

**Q7. 데모를 먼저 볼 수 있나요?**
네, 무료입니다. 문의 주시면 데모 링크(noshow.n9n.co.kr)를 바로 안내드리고, 손님 역할·사장님 역할 양쪽 화면을 직접 눌러보실 수 있습니다.

## B. 숨고 킷

### B-1. 프로필 소개문

전화 응대에 시술 흐름이 끊기고, 예약 확인·리마인더를 손으로 보내다 노쇼를 놓치는 미용실·피부관리실·네일샵 사장님을 위해 예약·노쇼 자동화를 만들고 설치해 드립니다.

- 손님이 전화 없이 직접 예약하는 온라인 예약 링크
- 예약확정·전일·당일 자동 리마인더 (카카오 알림톡/문자)
- 리마인더 무응답 시 노쇼 위험 자동 표시
- 취소 발생 시 대기명단 자동 제안으로 빈 자리 매출 회복

말로 설명드리기 전에 실제로 작동하는 데모를 먼저 보여드립니다. 견적 요청 주시면 데모 링크와 함께 가게 상황에 맞는 견적을 안내해 드립니다.

### C-2. 페인 섹션

**"이런 하루, 익숙하시죠"**

1. **가위 들고 있는데 전화가 울립니다.** 손님 응대 중에 예약 문의 전화까지 받아야 하니 시술 흐름이 끊기고, 지금 앞에 계신 손님께 죄송해집니다.
2. **예약 확인 카톡을 손으로 하나하나 보냅니다.** 하루가 끝나갈 때쯤이면 리마인더 보내는 것도 깜빡하고, 다음날 손님이 그냥 안 오십니다.
3. **취소된 자리가 그냥 빕니다.** 갑자기 취소 연락이 오면 대기 중인 다른 손님이 있었는데도 미처 연락 못 드리고, 그 시간은 매출 없이 지나갑니다.

### C-3. 작동방식 3단계

**"이렇게 자동으로 돌아갑니다"**

1. **손님이 직접 예약합니다.** 카톡 링크나 인스타 프로필로 들어와서 시술과 원하는 시간을 고르면 예약이 잡힙니다. 전화 없이요.
2. **리마인더가 알아서 나갑니다.** 예약 확정 즉시, 그리고 하루 전·당일에 자동으로 확인 메시지가 발송됩니다.
3. **취소되면 대기 손님이 채워줍니다.** 예약이 취소되면 대기명단에 있는 손님에게 자동으로 제안 메시지가 가고, 빈 자리가 매출로 돌아옵니다.

**Q. 데모의 카톡은 실제로 오는 건가요?**
데모는 화면 안 시뮬레이션입니다. 실서비스는 카카오 알림톡 또는 문자로 실제 발송되도록 설정해 드립니다.

**Q. 우리 가게에 맞게 커스터마이징 되나요?**
네. 시술 메뉴, 영업시간, 리마인더 문구, 노쇼 기준을 가게 상황에 맞춰 설정합니다.

**Q. 월 관리비는 왜 내야 하나요?**
매일 메시지가 나가려면 발송 인프라가 계속 살아 있어야 하고 오류 대응도 필요합니다. 셋업만 하고 방치되지 않도록 하는 비용입니다.

**Q. 해지하면 어떻게 되나요?**
다음 결제 주기부터 중단됩니다. 예약 데이터는 요청 시 정리해서 보내드립니다.

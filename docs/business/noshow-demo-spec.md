# 노쇼가드 (NoShowGuard) — 미용실 예약·노쇼 자동화 데모 스펙

> Growth-142 트랙. 검증수요-먼저 서비스 온램프(wiki `smb-ai-services-first-offer-2026-07`)의 첫 실행물.
> 벤치마크: ieumax.com (공개 랜딩 + 가격표 + 데모), 크몽 gig 665242 (니치다운 + 무료 데모 미끼).
> "노쇼가드"는 working name — founder 가 크몽 등록 시 변경 가능.

## 1. 오퍼 (무엇을 파는가)

미용실/피부관리실/네일샵 대상 **예약·노쇼 자동화 셋업 대행**:

1. **온라인 예약 링크** — 전화 응대 없이 고객이 직접 예약 (시술 선택 → 시간 슬롯 → 이름/연락처)
2. **자동 리마인더** — 예약 확정 즉시 확인 메시지, 전일 리마인더, 당일 리마인더 (실서비스: 카카오 알림톡/SMS)
3. **노쇼 방어** — 리마인더 무응답 시 노쇼 위험 표시, 사장이 한눈에 확인
4. **취소 → 대기명단 자동 채움** — 취소 발생 시 대기자에게 자동 제안, 빈 슬롯 매출 회복

가격 (그라운딩 앵커): 셋업 30만~50만원 + 월 관리 5만~13만원.

## 2. 데모 범위 (noshow.n9n.co.kr)

| 경로 | 대상 | 내용 |
|---|---|---|
| `/` | 잠재 고객(원장) | ieumax 스타일 랜딩: hero → 페인 → 작동방식 3단계 → **라이브 데모 CTA** → 가격표 3티어 → FAQ → 문의(크몽 링크) |
| `/demo` | 데모 방문자 = 손님 역할 | 실동작 예약 페이지: 시술 선택, 날짜/슬롯, 이름/연락처(가짜 허용) → 예약 생성 |
| `/admin` | 데모 방문자 = 사장 역할 | 대시보드: 오늘 예약 목록, 노쇼 위험 뱃지, 대기명단, **메시지 발송 로그**(카톡 스타일 말풍선) |

**핵심 데모 시나리오 (30초 영상 = 크몽 포트폴리오)**:
1. 손님이 `/demo`에서 예약 → `/admin` 메시지 로그에 확인 카톡이 즉시 뜬다
2. "시간 빨리감기" 데모 버튼 → 전일/당일 리마인더가 발송된다
3. 예약 하나를 취소 → 대기자에게 자동 제안 메시지가 발송되고 슬롯이 채워진다

## 3. 시뮬레이션 경계 (정직 표기)

- 데모의 메시지는 **실발송이 아니라 화면 내 카톡 스타일 시뮬레이터** (알림톡 실발송은 사업자번호+채널 등록 필요, 발송비 발생).
- 랜딩/데모에 명시: "데모는 발송 시뮬레이션입니다. 실서비스는 카카오 알림톡 또는 SMS(솔라피 등)로 실발송 설정해 드립니다."
- 데모 데이터는 **6시간마다 자동 리셋** (공개 데모 오염 방지). 리셋 주기 표기.

## 4. 기술 (기존 패턴 재사용)

- `services/noshow-demo/` — FastAPI + vanilla-htmx SPA (hanbang-rag `services/` 패턴), **SQLite in-container** (외부 DB 의존 0 — 데모는 리셋되는 게 장점, LLM 호출 0 = API 비 0)
- 리마인더 엔진: 실시계 스케줄 + 데모용 "시간 빨리감기"(demo clock offset) — 30초 시연을 위해 필수
- `deploy/preview/noshow-demo.compose.yml` — app-only, coolifynet external network, Traefik 라벨(hanbang-rag 카피), 쓰기 엔드포인트 ratelimit
- 디자인: 기존 데모 품질 기준(CDO 토큰), **서비스워커 금지**(pwa-sw-stale-cache), Pico 사용 시 `.app-*` max-width 해제(pico-container-maxwidth-shell)

## 5. 이 트랙의 preset 복리

첫 대행 건 수주 시 이 데모의 예약/리마인더/대기명단 로직이 그대로 고객 셋업의 베이스 → `presets/` 등록 후보. 대행 건마다 업종 변형(병의원/네일)이 preset 파라미터로 누적.

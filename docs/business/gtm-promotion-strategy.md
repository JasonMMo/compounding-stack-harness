## 1. 진단 — 왜 의뢰가 0인가

### 현황 인식

의뢰가 0인 것은 실패가 아니다. **수요생성(demand generation) 활동을 아직 하지 않았기 때문**이다. 파운더는 지금까지 제품(16종 라이브 데모, 7축 harness)을 만드는 데 집중했고, "알리는 행위"는 zero다. 깔때기 상단이 비어 있으면 하단(의뢰)이 비는 것이 정상이다.

### 왜 마켓플레이스(크몽/숨고)가 이 문제에 맞는가

| 문제 | 마켓플레이스 해법 |
|---|---|
| 인바운드 0 (파운더를 모름) | 수요가 이미 존재하는 플랫폼에 올라타는 것 = 수요 포착(demand capture) |
| 브랜드·SEO 없음 | 플랫폼 SEO 기생 — 내가 검색될 필요가 없음 |
| 콜드스타트 리뷰 0 | 플랫폼 자체 트래픽으로 첫 노출 확보 가능 |
| 솔로 파운더 1인 | 플랫폼이 결제·계약·분쟁 인프라를 대리 |
| 예산 0 | 게재비 무료, 수수료는 성사 후 |

**한계**: 마켓플레이스는 단가 상한이 있고, 자사 브랜드를 쌓기 어렵다. M2 획득 전술로 쓰되, M3 이후에는 자사 채널로 트래픽을 이전하는 계획이 필요하다.

### 첫 문의 → 유료고객(M2) 전환 동선

```
gig 노출
  → 잠재고객 "라이브 데모 확인" (링크 클릭, 즉시 신뢰 형성)
  → 크몽/숨고 채팅 첫 문의
  → 파운더: 30분 무료 니즈 인터뷰 제안 (사전 설문 2~3문항으로 사전 검증)
  → 인터뷰 후 견적서 1장 (당일)
  → 계약/착수금 50% → 납품 → 잔금 50%
  → 리뷰 요청 (필수 — 콜드스타트 탈출)
```

**사전 검증 2문항 (채팅 직전 자동화)**: ① 현재 어떤 시스템/방식으로 관리하시나요? ② 서버(온프레미스 또는 사내 클라우드)가 있으신가요? → Ⓐ는 인프라 보유 고객만 계속 진행 (CS 낭비 방지).

### 콜드스타트 리뷰 0 극복법

1. **M2 무료 3건 정책 활용**: revenue-roadmap 에 이미 "M2까지 3개사 무료, case study 권리 양도" 결정. 크몽/숨고 에서도 "포트폴리오 모집 특가" 프레이밍으로 3건 초저가 수주 → 리뷰 + 사례 확보.
2. **즉시 응답 SLA**: 크몽/숨고 는 응답속도를 노출 알고리즘에 반영. 1시간 내 첫 답변 원칙.
3. **데모 품질로 신뢰 선취**: 라이브 데모 16종이 "백 마디 설명보다 낫다" — 리뷰 없어도 데모 링크가 신뢰 앵커.
4. **첫 3건 리뷰 인센티브**: 납품 후 "구체적 후기 작성 시 수정 1회 무료 제공" 제안 (크몽 정책 위반 여부 확인 후 적용).

## 3. SNS 채널 평가 — 솔로 파운더 기준

### 채널 우선순위 (추천 2 + 보조 1)

| 순위 | 채널 | 이유 | 콘텐츠 형식 | 주당 빈도 |
|---|---|---|---|---|
| **1순위** | **네이버 블로그** | 한국 B2B SMB CEO/IT담당자 검색 생태계 핵심 — "업무시스템 제작", "사내망 ERP" 키워드 검색량 실재 | 라이브 데모 캡처 + 사례 설명 포스트 | 주 1회 |
| **2순위** | **디스콰이엇(Disquiet)** | 한국 스타트업·메이커 커뮤니티 — 제품 소개, 피드백, 초기 traction. B2B 개발도구/SaaS 사례 다수. 비용 0 | 제품 소개글 + 데모 링크 | 론칭 1회 + 월 1회 업데이트 |
| **보조** | **LinkedIn (CEO 명의)** | IT담당자·CTO 페르소나 접근 — "self-host AI" 포지셔닝이 LinkedIn 에서 반응 | 짧은 인사이트 포스트 + 데모 링크 | 격주 1회 |

### 채널별 데모 재활용법

- **네이버 블로그**: "물류회사 재고관리 시스템, 2주 안에 만든 방법 — AI 설계 + self-host" 형식. `logistics-demo.n9n.co.kr` 스크린샷 삽입 + 로그인 demo/demo 안내.
- **디스콰이엇**: 제품 페이지 등록 시 `gtm-landing.n9n.co.kr` 을 공식 랜딩으로 연결. 데모 9종 갤러리 형식으로 아키타입 소개 포스트 1건.
- **LinkedIn**: 짧은 단락 + "Before(엑셀/수기) → After(라이브 시스템)" 대비 이미지 1장.

### 오가닉 cadence (현실적)

```
월요일: 네이버 블로그 포스트 1편 (45분 작성)
격주 화요일: LinkedIn 짧은 포스트 (15분)
신규 데모/기능 출시 시: 디스콰이엇 업데이트 (30분)
```

총 주당 투입: **약 1시간 이하**. 솔로 파운더가 제품 개발과 병행 가능한 최소 cadence.

| **61~90일** | 효과 있는 채널에 예산 집중 + 없는 채널 중단, 두 번째 gig 개선 | 10만 | 계약 5건 누적, M2 게이트 확정 |

**총 예산 3개월**: 35만원 이하. charter §5 저비용 원칙 준수.

> 크몽 광고 노출 패키지: 카테고리 내 상단 노출 구매 기능 존재 (5만~15만원/월 수준). 효과는 카테고리·경쟁 강도에 따라 다름 — 먼저 오가닉으로 1~2주 운영해 기저 문의율 측정 후 유료 전환을 권장.

## 5. 측정 — 채널별 CAC·리드 추적

### 추적 지표 (간단 스프레드시트로 충분)

| 지표 | 측정 방법 | 기준 |
|---|---|---|
| **gig 노출수** | 크몽/숨고 대시보드 | 주간 추세 |
| **gig 클릭률(CTR)** | 대시보드 | < 2% 시 제목/썸네일 교체 |
| **문의 전환율** | (문의수/노출수) | 목표 ≥ 0.5% |
| **견적→계약 전환율** | 수동 집계 | 목표 ≥ 30% |
| **CAC(고객획득비용)** | 투입 시간×시간단가 + 광고비 / 계약건수 | 스타터 기준 ≤ 50만원 |
| **블로그 방문수** | 네이버 블로그 통계 | 포스트당 방문 50+ 목표 |

### 스케일 / 중단 판단 기준

| 신호 | 액션 |
|---|---|
| 30일 문의 0건 | gig 제목·썸네일 전면 교체, 카테고리 재검토 |
| CTR 1% 미만 | A/B 테스트: 제목 2안 교체 후 2주 재측정 |
| 문의 5건+ but 계약 0건 | 가격 또는 인터뷰 전환 스크립트 문제 → 가격 10~20% 인하 또는 무료 30분 컨설팅 제안 추가 |
| 계약 3건+ 달성 | M2 게이트 진입 선언, 리뷰 축적 후 정가 복귀 |
| 특정 채널 CAC > 100만원 | 해당 채널 예산 중단, 오가닉으로 복귀 |

## 7. Revenue Milestone 연계

이 전략은 **M2 — First Paid Customer** 게이트에 직접 기여한다.

| M2 게이트 조건 | 이 전략의 기여 |
|---|---|
| 첫 customer profile 작성 완료 | 크몽/숨고 문의 인터뷰 → profile 작성 원재료 |
| 첫 고객 도메인 scaffold + 실제 사내 운영 1주 | 계약 후 delivery loop (PM·engineer·QA loop) |
| ops pack (docker-compose + Vault + SSO) 배포 | 스탠다드/프리미엄 티어 deliverable 에 포함 |
| 결제 영수증 발행 | 크몽/숨고 플랫폼 또는 직접 계좌 이체 |

**M1 GTM Readiness 게이트 연계**: revenue-roadmap T-1~T-6 기술 성숙 6/6 달성. 남은 GTM 게이트 = **demo 영상 1건 + qualified lead 5건**. 이 전략의 크몽/숨고 gig 운영 + 네이버 블로그가 lead 5건 기준을 채운다. demo 영상은 라이브 데모 녹화 1건(OBS 5분)으로 저비용 충족 가능.

**M3 연계**: M2 첫 고객의 산업 = M3 vertical 결정. 크몽/숨고 에서 어느 산업 의뢰가 먼저 들어오느냐가 `domain-expert-<산업>` agent 우선 개발 입력값이 된다. 마켓플레이스 의뢰 데이터 = product roadmap signal.

# 법무법인 통합 업무관리 + AI 판례검색 — 영업 원페이저

> 인도물 전체 목록: [lawfirm-demo README](README.md) | 라이브 데모: `lawfirm-demo.n9n.co.kr` (demo/demo)

## 핵심 가치제안

**소송 데이터를 사내망 밖으로 한 바이트도 내보내지 않으면서, 사건관리·문서·결재·AI 판례검색을 하나의 흐름으로 연결한다.**

---

## 왜 지금 필요한가 — 3가지 현실 문제

| 현재 상황 | 문제 |
|---|---|
| 사건 정보를 엑셀·카카오톡·이메일로 공유 | 소송 비밀 외부 유출 위험. 이력 추적 불가 |
| 판례 검색은 외부 SaaS(유료 구독) | 월 구독료 + 검색 결과가 외부 서버에 기록됨 |
| 결재는 종이 또는 이메일 체인 | 결재 단계·이력 파악 불가. 감사 불가 |

---

## 페르소나별 베네핏

### CEO / 대표변호사 — 보안·통제·투자 타당성

- **데이터 주권 보장**: Docker self-host — 소송 데이터가 사내 서버에서만 처리됨. 외부 클라우드 API 호출 0건 (설치 런북으로 확인 가능).
- **전사 사건 현황 가시성**: 10건 이상의 사건 상태(접수·진행·재판·항소·종결)를 단일 화면에서 파악. 담당 변호사·다음 기일 한눈에.
- **예측 가능한 비용**: 클라우드 SaaS 월 구독료 없음. 서버 1대 운영 비용만. 사용량 증가에 따른 요금 폭증 없음.

### 업무담당자 (어소시에이트·사무장) — 실무 생산성

- **사건 흐름 일원화**: 사건 등록 → 당사자·문서 첨부 → 결재 상신 → AI 판례검색 진입까지 한 시스템 안에서 이동.
- **사건문서 체계화**: 소장·준비서면·증거·계약서를 유형별로 등록·버전 관리. 파일 분실·버전 혼선 해소.
- **AI 판례검색 즉시 진입**: 사건 검토 중 판례가 필요하면 상단 배너 클릭 1회로 AI 검색 화면으로 이동. 별도 브라우저 전환 불필요.

### IT 담당자 — 설치·보안·유지보수

- **Docker 단일 명령 설치**: `docker-compose up` 한 번. FastAPI + PostgreSQL + 프런트엔드 포함. 외부 의존 없음.
- **시크릿 환경변수 주입**: `SECRET_KEY` 등 민감값은 환경변수로만 주입. 평문 파일 미보관. 보안 감사 대응 가능.
- **접근 권한 세분화**: 문서별 부서/직원 단위 read/edit/admin 권한 설정. `GET /health` 헬스체크 내장.

## 왜 self-host인가 — SaaS 대비 비교

| 항목 | 외부 SaaS | self-host (이 제품) |
|---|---|---|
| 소송 데이터 위치 | 외부 서버 | 사내 서버 100% |
| 외부 유출 가능성 | 구조적으로 존재 | 구조적으로 없음 |
| 월 비용 | 사용량·사용자 수 비례 과금 | 서버 운영비만 (고정) |
| 인터넷 단절 시 | 서비스 불가 | 사내망 단독 가동 |
| 감사·컴플라이언스 | 외부 업체 정책 종속 | 완전 자체 통제 |

## 데모 시연 흐름 — 영업 미팅 5분 스크립트

```
[0:00] 홈 화면
  → 로그인(demo/demo) 후 도메인 카드 4개 + "AI 판례검색" 상단 배너 확인
  → "데이터는 이 서버 밖으로 나가지 않습니다" 한 마디

[1:00] 사건관리 (법무)
  → 사건 목록 : 10건, 상태·담당 변호사·기일 표시
  → 사건 상세 클릭 : CASE-2024-001 "기업 인수합병 계약 분쟁" — 당사자·문서 탭 이동
  → 신규 사건 등록 폼 시연 (30초)

[2:00] 문서관리
  → 소장·준비서면 등록, 버전 이력 확인
  → 부서별 접근규칙 설정 화면 (IT 담당자용 포인트)

[2:45] 전자결재
  → 결재요청 목록 : 연차·출장비·계약체결 유형 분류
  → 결재 상세 : 팀장→파트너→대표 단계 흐름, 현재 단계 하이라이트
  → 결재 승인/반려 버튼 시연

[3:30] AI 판례검색 핸드오프 (killer-app)
  → 상단 배너 "AI 판례검색" 클릭 → legal-rag.n9n.co.kr/pro 새 탭 오픈
  → 키워드 + 의미 하이브리드 검색 시연 : "계약 불이행" 입력
  → 판례 원문 드로어 : 인용 문단 하이라이트 표시
  ※ 정직 고지: 생성형 AI 답변이 아닌 검색·인용만 제공. 변호사가 최종 판단.
  ※ 정직 고지: 현재 별도 로그인 필요 (SSO 미지원, 로드맵 예정).

[4:30] 마무리
  → "설치는 Docker 한 번, 운영은 사내 서버, 월 구독료 없음"
  → 질문 및 견적 협의
```

- 비인증 레이아웃: 헤더-최소 + 메인-최소. 사이드바·배너·persona-select 없음.
- `autocomplete="username"` / `autocomplete="current-password"`.
- 오류: 401 → 폼 재렌더, `role="alert"` 오류 메시지 (aria-live).

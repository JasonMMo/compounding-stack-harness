# 화면 데모 시나리오 — 법무법인 데모 (lawfirm-demo)

## 시나리오 개요

- 페르소나: 민사 사건 담당 변호사 (재판 전략 수립 전 관련 판례 수집 단계)
- 화면: 판례 검색 (`legal_precedent_search.html`)
- 목표: 담당 사건과 관련된 판례를 키워드 검색으로 확인하고, 사건 유형 필터로 범위를 좁히는 흐름 시연
- 시연 소요 시간: 약 3분

---

## 시연 흐름

### 1단계 — 화면 진입

브라우저에서 판례 검색 화면을 엽니다.

- 화면 상단에 "판례 검색" 제목이 표시됩니다.
- 검색어 입력 필드, 사건 유형 드롭다운, 검색 버튼이 보입니다.
- 결과 영역에는 "검색어를 입력하고 검색 버튼을 누르세요." 안내 문구가 표시됩니다.

---

### 2단계 — 키워드 검색

검색어 입력 필드에 `손해배상` 을 입력하고 "검색" 버튼을 클릭합니다.

- 사건 유형 드롭다운은 "모든 유형" (기본값) 상태로 둡니다.

예상 결과:

- 결과 영역에 "검색 결과 2건" 문구와 함께 판례 카드 2개가 표시됩니다.
- 카드 1: 인용 `대법원 2020다12345` / 유형 배지 `민사` / 법원 `대법원` / 선고일 `2020-05-21`
- 카드 2: 인용 `서울고등법원 2019나56789` / 유형 배지 `민사` / 법원 `서울고등법원` / 선고일 `2019-11-30`
- 각 카드에 판결 요지 300자와 키워드가 표시됩니다.

---

### 3단계 — 사건 유형 필터 적용

검색어 `손해배상` 을 유지한 채 사건 유형 드롭다운에서 "민사" 를 선택하고 "검색" 버튼을 클릭합니다.

예상 결과:

- 반환된 모든 카드의 유형 배지가 `민사` 입니다.
- 결과 건수와 카드 내용이 2단계와 동일합니다 (데모 데이터의 손해배상 판례가 전부 민사이기 때문).

설명 포인트: 필터를 "형사" 로 변경하면 손해배상 판례가 형사 사건에 없으므로 "검색 결과가 없습니다." 가 표시됩니다.

---

### 4단계 — 다른 키워드 검색

검색어를 `자백` 으로 변경하고 사건 유형을 "모든 유형" 으로 초기화한 뒤 검색합니다.

예상 결과:

- 자백 관련 판례 카드가 1건 이상 표시됩니다.
- 카드에 해당 판례의 인용·법원·선고일·요지·키워드가 표시됩니다.

---

### 5단계 — 빈 결과 처리 확인

검색어를 데이터에 없는 단어 (예: `존재하지않는검색어`) 로 입력하고 검색합니다.

예상 결과:

- 결과 영역에 "검색 결과가 없습니다." 문구가 표시됩니다.
- 오류 없이 정상 처리됩니다.

---

## 시연 주의 사항

- 이 화면이 제공하는 기능은 키워드 full-text 검색과 사건 유형 필터입니다.
- 판례 전문 열람, 사용자 로그인, 재판 전략 생성 기능은 이번 인도 범위에 없습니다.
- 시연 데이터는 `scripts/demo/setup_lawfirm.py` 가 적재한 5건의 판례입니다. 실제 판례 DB 연동은 별도 구성이 필요합니다.

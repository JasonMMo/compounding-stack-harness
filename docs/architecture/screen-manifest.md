# Screen Manifest — JSON Contract

> `out/<profile>/screen-manifest.json` — single source of field metadata for frontend rendering.
> Generated by `scripts/workflow/manifest.py` via `scripts/workflow/scaffold.py`.
> Frontend **reads** this; it never reimplements column classification logic.

## 1. JSON Shape

```json
{
  "profile": "shop-demo",
  "catalog_version": "1.0",

  "customer_display": "ACME 코퍼레이션",
  "domains": [
    {
      "slug": "sales",
      "display": "영업",
      "entities": ["sales-order", "sales-order-line"]
    }
  ],
  "feedback_url": "https://forms.example.com/feedback",

  "entities": {
    "<entity-key>": {
      "domain": "sales",
      "table": "sales_sales_order",
      "label": "Sales Order",
      "fields": [
        {
          "name": "order_number",
          "type": "string",
          "required": true,
          "label": "Order Number",
          "unique": true,
          "control": "text",
          "max_length": 255
        },
        {
          "name": "status",
          "type": "enum",
          "required": true,
          "label": "Status",
          "control": "select",
          "options": ["draft", "confirmed", "partially-fulfilled", "fulfilled", "cancelled"]
        },
        {
          "name": "order_id",
          "type": "uuid",
          "required": true,
          "label": "Order Id",
          "control": "fk-text",
          "fk_entity": "sales-order",
          "note": "FK dropdown deferred (M1)"
        }
      ],
      "hidden_fields": ["id", "created_at", "updated_at"]
    }
  }
}
```

### Top-level optional fields (Growth-39)

| Field | Type | Source | When present |
|---|---|---|---|
| `customer_display` | string | `profile.customer.display` | scaffold.py passes profile dict; absent in manifest.py CLI mode |
| `domains` | array | `profile.domains[].{slug,display,entities}` | same as above; entities filtered to those scaffolded |
| `feedback_url` | string | `profile.overlay.feedback_url` | only when profile sets this key |

`domains[].entities` contains only entity keys that appear in this manifest's `entities` map.
Frontend reads `customer_display` for the home-screen heading; `domains` for domain cards; `feedback_url` for the CTA link.
All three are absent (not null) when the manifest was produced by the `manifest.py` CLI without a profile — frontend must handle their absence gracefully.

## 2. Column Classification Rules

These rules live in `manifest.py::_classify_column()` — do not reimplement elsewhere.

| Priority | Condition | `control` | Extra fields |
|---|---|---|---|
| 1 | column has `fk` | `fk-text` | `fk_entity`, `note: "FK dropdown deferred (M1)"` |
| 2 | `type: enum` | `select` | `options`: catalog `values` list |
| 3 | `type: string` | `text` | `max_length` from catalog `length` if present |
| 4 | `type: text` | `textarea` | — |
| 5 | `type: integer` or `decimal` | `number` | — |
| 6 | `type: boolean` | `checkbox` | — |
| 7 | `type: date` | `date` | — |
| 8 | `type: timestamp` (non-system) | `datetime` | — |
| 9 | `type: uuid` (no FK) | `text` | — |

**Hidden fields**: columns named `id`, `created_at`, or `updated_at` are excluded from `fields` and listed in `hidden_fields` instead.

**`required`**: `true` when `nullable: false` in catalog.

**`unique`**: carried as `true` when catalog column sets `unique: true`; omitted otherwise.

**`max_length`**: present on `text` controls only when the catalog column sets a `length`. Absent means no limit — the frontend must not impose one.

**`label`**: column name with underscores → spaces, each word Title-cased.

**Entity `label`**: entity key with hyphens → spaces, Title-cased.

**Field order**: catalog column definition order (minus hidden fields). Deterministic across runs.

## 3. Determinism Guarantee

`build_manifest()` is a pure function:
- Input: `(profile_slug, entity_keys, catalog)` — all in-memory dicts.
- Output: same dict bytes across every run given identical inputs.
- No timestamps, no UUIDs, no wall-clock reads.
- JSON serialization: `json.dumps(..., indent=2, sort_keys=False)` — preserves catalog column order.

Two invocations with the same catalog produce byte-identical `screen-manifest.json`.

## 4. Derivation & Storage

- `out/<profile>/screen-manifest.json` is a **derived artifact** — `out/` is gitignored (`.gitignore`).
- Single source: `presets/ddl/catalog.yaml` (via `render.py::load_catalog()`).
- Regenerate at any time: `python scripts/workflow/scaffold.py --profile <slug>`.

## 5. Frontend Contract

- Frontend adapter reads `PROFILE_MANIFEST=<path>` env var at startup.
- Frontend **reads** the manifest; it never writes to it or re-derives field rules.
- FK `control: fk-text` renders as a plain text input in Phase 1; full FK dropdown is M1+ gated.
- Phase 2 will wire the manifest path from scaffold.py's printed run command.

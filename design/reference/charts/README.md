# charts.csv — chart-selection decision table

데이터 타입 → 차트 유형 결정표 (25행). 컬럼: Data Type · Best Chart Type · Secondary Options · When to Use · **When NOT to Use** · Data Volume Threshold · Color Guidance · Accessibility Grade/Notes/Fallback · Library Recommendation · Interactive Level.

## 용도

**business-system 대시보드** deliverable(entity→DDL→typed-form 경로)에서 차트 컴포넌트 선택 시 참조. impeccable·`presets/themes/`(8축)는 차트 선택을 다루지 않으므로 그 갭을 메우는 외부 레퍼런스. 디자인 craft 의 단일 진실은 여전히 impeccable — 이 표는 data-viz **결정 보조**일 뿐 자동 드라이버 아님.

활성 대시보드 작업이 생기면 이 표를 `knowledge/wiki/` 프로즈로 환류 검토. 판정 맥락: 메모리 `official-skill-adoption-policy`.

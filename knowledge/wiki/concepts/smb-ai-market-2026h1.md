## 1. 검증된 것 / 미검증된 것

| 가설 | 판정 | 근거 |
|---|---|---|
| 홈페이지/랜딩 제작 = 레드오션 | **검증 [강함]** | 크몽 5천원~, 리뷰 수백~천 건 극단 가격경쟁 |
| AI 기능성 외주 공급 얇음 | **검증 [강함]** | 크몽 BEST 20 AI특화 미노출, 'AI LLM RAG MVP' 리뷰 2건 |
| self-host "데이터유출 0" 구매요인 | **규제업종만 검증** | PIPA §23·28·29 가 Cloud LLM 사용 법적 제약 → 의료·법률·금융 self-host = 규정준수 필수. 일반 SMB는 미검증 |
| 월 API비 0 가격경쟁력 | **조건부 [약함]** | API 종량 별도청구가 시장관행임은 확인, 실절감액 미정량화 |
| 일반 SMB self-host 프리미엄 지불 | **미검증** | 의향 설문(보안우려=장벽, N=315)만, WTP 금액 증거 없음 |

## 2. 스코프 결론

- **① 지불의사**: 실제 결제는 **챗봇 외주(크몽 3~5만원, 리뷰 수십~수백)** 와 **업무자동화(평균 20만원)** 에 몰림 — 전량 **일회성 구축비**. RAG·사내검색·리뷰분류는 관심만, 지불 증거 없음.
- **② 공급**: SaaS 챗봇(채널톡 22만+사)은 대형 공급자 선점. 그러나 **크몽/숨고 AI 기능성 *개발 외주*에는 AI 특화 공급자 공백**(데이터 확인).
- **③ 과금**: 크몽 외주 전량 일회성(20~200만원+), 채널톡만 월구독+종량. self-host TCO 우위는 논리적이나 정량 실사례 없음.
- **④ self-host**: 규제업종은 PIPA로 self-host 필수. 일반 SMB는 보안우려=채택장벽이나 프리미엄 전환 금액 미증명.

## 3. 진입 use case (도출)

1. **[1순위] 규제업종(의료·법률·금융) 사내 AI RAG — self-host 법적 필수**. 공급 공백 + 법적 압력 기반 지불의사 + 데이터유출0/API비0 교집합 최대. 1차 타깃: 소형 법무법인·개인 의원·소형 대부업. 우리 자산 직결: [[legal-ai-search-strategy]] · `domain-expert-legal` · [[smb-ai-guide-lite]]. **미검증: 실 WTP·의사결정 사이클 → 3~5곳 인터뷰**.
2. **[2순위] 일반 SMB 업무자동화 + RAG 외주 (크몽 진입)**. AI 도입장애 1위 "맞춤형 응용서비스 부족"(64%) + 크몽 AI 공백. 패키지: 30만(FAQ챗봇)/80만(사내RAG MVP)/150만+(자동화). 리뷰 5~10건 조기확보가 관건. **미검증: 전환율 → 크몽 등록 후 2~4주 문의수 관찰**.

## 4. 포지셔닝 시사 (CTO 판정)

- **창끝은 규제업종 self-host RAG** — self-host가 "선택"이 아닌 "법적 필수"인 유일하게 검증된 세그먼트. 여기서 우리 임베딩 자산이 moat.
- **일반 SMB엔 "프리미엄" 아닌 "API비 없는 고정 TCO + 사내데이터 안전"** 으로 정직하게. 프리미엄 지불의사는 데이터가 없음.
- 지불은 **일회성 구축비** 중심 → 월구독 가정 말 것. 운영 월비는 self-host 실비로 최소화가 메시지.
